# CMS — làm nhanh trong 1 trang

**Web khách:** https://vinfast3scamau.com  
**Vào sửa:** https://cms.vinfast3scamau.com/admin/login  

---

## Đổi giá / ưu đãi xe
**Ô tô** hoặc **Xe máy** → sửa trên thẻ → **Lưu thẻ**

## Đổi phụ kiện
**Phụ kiện** → sửa tên/giá/còn hàng → **Lưu thẻ**

## Thêm xe mới
**Thêm ô tô** → chọn xe mẫu + đặt tên → **Tạo nháp**  
→ upload ảnh → sửa nội dung → **Xuất bản** → xem web

## Copy xe gần giống
Trang chi tiết xe → **Nhân bản** → đặt tên → upload ảnh → **Xuất bản**

## Ẩn xe / Xóa xe
Ẩn: **Chuyển nháp** hoặc **Lưu trữ**  
Xóa: **Xóa** (không lấy lại được)

## Đăng tin
**Tin tức → Viết bài mới** → **Xuất bản**

## Gọi khách form
**Lead khách** → **Gọi** → đổi **Đang xử lý** / **Chốt** / **Đóng**

## Sửa trang chủ
**Trang chủ** → bấm chữ/ảnh → **Lưu thay đổi** (thanh dưới)

## Đổi hotline góc web
**Nút nổi** → sửa → **Lưu**  
(+ **SEO → Cài đặt chung** nếu đổi hotline chính)

## Web chưa hiện nội dung mới
**Tổng quan → Làm mới cache** → Ctrl+F5 trên web
